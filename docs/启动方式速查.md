# AIChat · 启动方式速查

## 📍 软件目录
```
/Users/chenzhichao/AIChat
```

## 📍 数据目录（会话/记忆/皮肤配置，独立不随软件目录变动）
```
~/.aichat/   (即 /Users/chenzhichao/.aichat/)
```

## ✅ 方式 1：双击启动（推荐）
在 Finder 进入本目录，双击 `AIChat.command` 即可。

> 首次提示"未验证开发者" → 右键 AIChat.command → 打开 → 再次点击「打开」。

## ✅ 方式 2：命令行
```bash
cd /Users/chenzhichao/AIChat
python3 main.py
```

## ✅ 方式 3：打包成 Mac App（以后发版用）
双击 `build_app.command`，生成 dist/AIChat.app。
